# DevForge skills

This extension provides developer skills. Activate the matching skill when a task fits:
codebase-onboarding (unfamiliar repo), reviewing-code-changes (PR/diff review),
secure-code-review (security audit), test-generation (writing tests),
bug-reproduction (bugs, regressions, flaky tests), safe-refactoring (refactors),
performance-profiling (slow code), dependency-audit (CVEs, verifying packages before install),
writing-commits-and-prs (commit messages, PR descriptions), llm-app-evals (evaluating prompts/RAG/agents),
prompt-injection-defense (securing LLM apps), session-handoff (pausing or handing off work),
skill-authoring (creating skills).
